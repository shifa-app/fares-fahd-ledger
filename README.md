# فارس وفهد للحسابات — FF (فارس للثقة، فهد للسرعة)

تطبيق أندرويد Flutter — برنامج حسابات دائن/مدين (المرحلة الأولى).
داخلي لفريق العمل فقط. حفظ محلي Offline-First (SQLite)، بلا خادم وبلا Firebase.

- **Package:** `com.faresfahd.ledger` — أندرويد فقط (1.0.2+3)
- **الدخول:** بالإيميل الشخصي فقط، يُحفظ محلياً كهوية للنسخة الاحتياطية. بلا OTP وبلا كلمة مرور.
- **المبالغ:** بالجنيه المصري. أخضر = له (مقبوضات)، أحمر = عليه (ديون).

## المميزات (المرحلة الأولى فقط)

1. شاشة دخول بالإيميل الشخصي.
2. قائمة أشخاص (عميل/مورّد) مع بحث بالاسم أو التليفون، والرصيد النهائي أمام كل واحد.
3. بطاقة الشخص: الاسم، التليفون، العنوان، النوع، ملاحظات + سجل نشاطات
   (بيع آجل، شراء آجل، دفعة مستلمة، دفعة مدفوعة، خصم) مع الرصيد بعد كل حركة.
4. إدخال بنقرة واحدة: زر (+ دين جديد / + دفعة) ولوحة أرقام مدمجة.
5. ملخص عام: اللي ليك / اللي عليك / الصافي.
6. كشف حساب PDF عربي (خط Noto Naskh Arabic مضمّن) للمشاركة/الطباعة.
7. نسخة احتياطية: تصدير كل البيانات ملف JSON ومشاركته عبر تطبيقات
   النظام (الإيميل الشخصي)، واسترجاع بلصق محتوى ملف JSON.
8. تذكير واتساب عادي عبر رابط `wa.me` — بلا WhatsApp Business API.

### النسخة السحابية التلقائية — الكود مكتمل، والإعداد الخارجي معلق

`lib/services/cloud_backup_service.dart` (حزمتا `google_sign_in` و
`googleapis`): دخول جوجل مرة واحدة بنطاق `drive.appdata`، ورفع JSON
تلقائي بعد كل تغيير (إضافة شخص/معاملة، حذف، استرجاع) إلى مجلد
`appDataFolder` المخفي في Drive، وبحث تلقائي عند تسجيل الدخول على
تثبيت جديد وعرض استرجاع النسخة إن وجدت، مع بقاء التصدير/الاستيراد
اليدوي بديلاً.

**شاشة الحالة (1.0.3، مثل تطبيق كناش المرجعي):** نافذة السحابة تعرض
في الأعلى «الحالة:» — «اكتمل النسخ الاحتياطي» بالأخضر عند نجاح آخر
رفع (مع تاريخ ووقت آخر رفع)، أو «لم يتم النسخ بعد» بالرمادي عند
الدخول بلا رفع، أو «غير مسجل بحساب جوجل بعد» قبل الدخول — مع نص
توضيحي: النسخ يتم تلقائياً بعد كل تغيير متى كان الهاتف متصلاً
بالإنترنت، وعند إعادة التثبيت سجّل الدخول بنفس حساب جوجل لاسترجاع
بياناتك. وبعد رفع ناجح يظهر «جميع المعاملات منسوخة» مع صفين بعلامة
صح خضراء: «الأشخاص» و«المعاملات» بأعدادهما الحقيقية من قاعدة
البيانات المحلية (`LedgerDb.counts()`).

## اختبار يدوي بعد التثبيت

1. **الدخول:** افتح التطبيق، أدخل إيميلك الشخصي، اضغط «دخول».
2. **إضافة شخص:** زر «إضافة شخص»، املأ الاسم والتليفون والعنوان، اختر
   عميل/مورّد، احفظ.
3. **تسجيل معاملة:** افتح بطاقة الشخص، اضغط «+ دين جديد» أو «+ دفعة»،
   أدخل المبلغ بلوحة الأرقام، احفظ — لاحظ تحديث الرصيد فوراً.
4. **الملخص:** من الرئيسية، تأكد أن «اللي ليك / اللي عليك / الصافي»
   تتغير مع المعاملات.
5. **كشف PDF:** من بطاقة الشخص اضغط «كشف PDF» وشاركه — تأكد أن
   الترويسة «فارس وفهد للحسابات» وأن الحركات والرصيد صحيحة.
6. **واتساب:** اضغط «واتساب» — يجب أن يفتح واتساب العادي على رقم الشخص
   مع رسالة التذكير جاهزة.
7. **النسخة الاحتياطية:** من الرئيسية اضغط أيقونة النسخة، شارك الملف
   إلى إيميلك الشخصي. للاسترجاع: أيقونة الاسترجاع، افتح الملف من
   الإيميل، انسخ محتواه كاملاً، الصقه في الحقل، اضغط «استرجاع»،
   وتأكد من عودة الأشخاص والحركات.

## ملفات الكود الرئيسية

- `lib/main.dart` — نقطة الدخول، واجهة عربية RTL، ثيم Cairo بالألوان المعتمدة
- `lib/app_info.dart` — هوية التطبيق (الاسم، FF، الشعار، ألوان الدليل المعتمد)
- `lib/logic/balance.dart` — منطق الرصيد الخالص (قابل للاختبار) + تنسيق التاريخ وكلمة التوضيح وفلاتر الأشخاص
- `lib/models.dart` — Person و LedgerEntry
- `lib/db/ledger_db.dart` — قاعدة SQLite المحلية + التصدير/الاسترجاع + إعدادات عامة (حالة السحابة)
- `lib/services/backup_service.dart` — تصدير JSON ومشاركته
- `lib/services/cloud_backup_service.dart` — النسخة السحابية التلقائية (دخول جوجل + Drive appDataFolder)
- `lib/services/pdf_service.dart` — كشف الحساب PDF
- `lib/services/whatsapp_service.dart` — رسائل وترويسة wa.me
- `lib/screens/` — الدخول، الرئيسية، بطاقة الشخص
- `lib/widgets/amount_sheet.dart` — لوحة الأرقام وإدخال المعاملة
- `lib/widgets/charts.dart` — منحنى سلس مع تظليل + ضغط لعرض قيمة اليوم، وأعمدة وارد/صادر
- `lib/widgets/flat_logo.dart` — الشعار المسطح المرسوم برمجياً (ف + سهم صاعد)
- `lib/widgets/person_form.dart` — نموذج إضافة/تعديل شخص (أزرار Segmented + استيراد من جهات الاتصال)
- `test/balance_test.dart` — 14 اختباراً لمنطق الرصيد
- `test/ui_logic_test.dart` — 21 اختباراً لمنطق الواجهة الجديد (التاريخ، التوضيح، الفلاتر، الألوان، الشعار، كبسولة الصافي، المسميات المختصرة)
- `assets/fonts/` — خط Noto Naskh Arabic (عادي + عريض) للـ PDF، وخط Cairo المتغير لواجهة التطبيق

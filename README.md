# فارس وفهد للحسابات

تطبيق أندرويد لبرنامج حسابات **دائن ومدين** — للعملاء والمورّدين: سجّل
الديون والدفعات وتابع أرصدة «له / عليه» أولاً بأول.

## الحسابات

- قائمة **أشخاص** (عميل / مورّد) مع بحث بالاسم أو التليفون، والرصيد
  النهائي أمام كل شخص.
- بطاقة الشخص: الاسم والتليفون والعنوان والنوع والملاحظات، مع سجل
  النشاطات (بيع آجل، شراء آجل، دفعة مستلمة، دفعة مدفوعة، خصم) والرصيد
  بعد كل حركة.
- إدخال بنقرة واحدة: زر «دين جديد / دفعة» مع لوحة أرقام مدمجة.
- ملخص عام: **اللي ليك / اللي عليك / الصافي** — بطاقة «صافي المستحقات»
  مع كبسولة «مديونية عملاء» عندما يكون الصافي لنا، و«مديونية علينا»
  عندما يكون الصافي علينا.

## المزايا

- **كشف حساب PDF بالعربية** لكل شخص، للمشاركة أو الطباعة.
- **تذكير واتساب** برسالة جاهزة عبر رابط `wa.me` على رقم الشخص.
- **نسخة احتياطية**: تصدير كل البيانات ملف JSON ومشاركته، واسترجاع
  بلصق محتوى الملف. ونسخة سحابية تلقائية إلى Google Drive بعد تسجيل
  الدخول بحساب جوجل — تتطلب إعداد مشروع Google Cloud (تفعيل Drive API
  وإنشاء OAuth لأندرويد) قبل أن تعمل.
- **يعمل دون اتصال**: البيانات محفوظة محلياً على جهازك.
- الدخول بالإيميل الشخصي فقط، بلا كلمة مرور.
- المبالغ بالجنيه المصري: أخضر = له (مقبوضات)، أحمر = عليه (ديون).

حمّل ملف الـ APK من صفحة **الإصدارات (Releases)** في هذا المستودع، وثبّته على جهاز أندرويد.
